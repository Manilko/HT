KEY ARCHITECTURAL PATTERNS:

iOS:
  • MVVM: Each screen has View + ViewModel
  • Coordinator: Navigation routing via AppCoordinator
  • Dependency Injection: Services via protocols + mocks
  • async/await: Modern concurrent programming

Backend:
  • Service/Repository: Business logic separated from data access
  • Middleware: Cross-cutting concerns (auth, error handling)
  • Modular: Each feature has dedicated module directory
  • Type-safe: Full TypeScript strict mode
